Webflow Proxy

This is a Cloudflare Pages site that proxies a Webflow domain and removes the Webflow badge.

Status

If you're seeing this page, the proxy is not yet configured or is not running correctly.

Make sure you've updated the config.js file with your Webflow domain.

Setup

  1. Update the config.js file with your Webflow domain
  2. Run npm run dev to test locally
  3. Deploy with npm run deploy
